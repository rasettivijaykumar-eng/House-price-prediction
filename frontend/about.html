How it works

Understanding the machine learning behind the estimate

Supervised learning means the model learns from examples where the correct target value is already known. In this project, the model learns from past houses with known sale prices.

Regression is a supervised learning task where the output is a continuous numerical value, such as a house price instead of a class label like cat or dog.

House-price prediction is a regression problem because the target is a numeric price value. The model tries to learn how property features are associated with price.

Before training, the dataset is cleaned, missing values are handled, duplicates are removed, locations are normalized, and numerical columns are adjusted for outliers. The location feature is converted into numeric values using one-hot encoding so the model can understand the categorical information.

After preparation, data is split into training and testing sets. Several regression algorithms are trained and evaluated using MAE, MSE, RMSE, and R². The best model is selected using the strongest overall performance.
